# Provincia de Los Ríos – sitio web educativo

## Contenido
- `index.html`: página principal.
- `cantones/`: 13 páginas individuales.
- `assets/styles.css`: estilos.
- `assets/app.js`: menú y tarjetas.
- `assets/los-rios-ilustracion.svg`: ilustración decorativa original.

## Cómo probar
Abre `index.html` en un navegador.

## Cómo publicar en GitHub Pages
1. Crea un repositorio público llamado `provincia-los-rios`.
2. Sube TODO el contenido de esta carpeta (no solamente el ZIP).
3. En Settings > Pages, elige Deploy from a branch, `main` y `/ (root)`.
4. Guarda y espera a que GitHub Pages publique la página.

## Nota de verificación
La población por cantón es la reportada para el Censo 2022. Los alcaldes se identifican según el directorio AME del período 2023–2027. Las parroquias, atractivos y gastronomía son reseñas introductorias; confirmar con los GAD cantonales. La Gobernación y otras autoridades pueden cambiar: revisar fuentes oficiales antes de entregar.
